# Amalthea.jl v1.1.0

This release adds the separate `amalthea-native` 0.1.0 beta: GNLSE and capillary
simulations from Python with a Rust CPU solver and no Julia runtime. It also
repairs fourth-order propagation, Raman coefficient accuracy, spectral
diagnostics, scan argument handling and PPT fallback/cache behavior.

## Python beta

`amalthea_native` supports scalar and modal carrier/envelope capillaries,
polarization, gas mixtures, ADK/PPT plasma, molecular Raman, changing pressure
and radius profiles, custom modes and complete-array nonlinear callbacks.
Results own their NumPy arrays and save to NPZ or optional HDF5. Execution
metadata identifies the evaluator and fallback reasons.

The CPU wheel targets are CPython 3.11–3.14 on Linux x86_64 and ARM64
(glibc 2.28 or later), macOS Apple Silicon and Windows x86_64. Download the
matching `amalthea_native-0.1.0-...whl` from this release, verify it against
`SHA256SUMS.txt`, and install it in a virtual environment:

```sh
python -m pip install --only-binary=:all: /path/to/amalthea_native-0.1.0-TAGS.whl
```

For HDF5, append `[hdf5]` to the quoted wheel path. Dependencies include NumPy,
SciPy, CoolProp 7.2.0 and mpmath; install them before going offline. The wheels
need no Rust compiler, system FFTW or libcubature. See the
[Python guide](https://vdiego28.github.io/Amalthea.jl/stable/python_native.html)
for units, examples, callbacks and actual backend selection.

Quantum noise, envelope plasma and vector Raman requests fail explicitly.
Python GPU, free-space and step-index entrypoints are outside this beta.
The existing `amalthea` Python package remains the Julia-backed interface.

## Correctness and maintenance

- `locextrap=false` now evaluates derivatives at the accepted fourth-order
  state across Julia, legacy Rust, resident CPU and CUDA. Dense output reaches
  that endpoint continuously. Default fifth-order stepping is unchanged.
- Small-time-step Raman forcing coefficients avoid cancellation and retain
  the finite zero-frequency limit.
- `Processing.spectral_phase` centers the complex spectrum before unwrapping
  along frequency; `getφ` remains a deprecated alias. Time-bandwidth products
  honor mode summation.
- The separate Rust `Dopri5Stepper` helper correctly transports accepted
  nonlinear contributions and applies PI/rejection control.
- Spline interval initialization, gradient gas metadata, scan argument
  ownership and notebook construction are repaired.
- Missing native libraries correctly select the Julia PPT fallback. Atomic
  standalone PPT cache publication retries bounded Windows contention.
- Built-in scalar-gradient dispersion setup is batched in Python. Custom
  models retain their own evaluation path.

Fourth-order trajectories, phase diagnostics and mode-summed bandwidth
products may differ from v1.0.4 because these errors are corrected. Recheck
stored results that relied on those behaviors. Variable linear operators keep
Julia's endpoint-exponential convention; refine propagation step bounds for
profile convergence as explained in the Python guide.

## Julia installation

```julia
using Pkg
Pkg.add(url="https://github.com/vdiego28/Amalthea.jl", rev="v1.1.0")
```

Julia 1.10 or later is required. Four portable CPU native libraries and their
checksums accompany the release. Julia installs the matching verified library
or compiles it from source. CUDA remains opt-in and requires a source build;
Python wheels and downloadable Julia libraries are CPU-only. Amalthea is
installed from GitHub, rather than Julia General.

The release assets include `release-manifest.json`, exact-source wheel
evidence and SHA-256 checksums. The source archive supports rebuilding the
Python distribution. Platform acceptance does not imply a universal speedup;
modal Python evaluation includes SciPy spatial integration.
